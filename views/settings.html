Cài đặt

Dữ liệu được lưu trong các file JSON ở thư mục data/ (bên cạnh file này).

Sao lưu

Tải toàn bộ dữ liệu (8 file JSON) về máy dưới dạng một file ZIP.

Hình nền trang

Hỗ trợ ảnh hoặc video (tối đa 50MB), lưu ngay trên trình duyệt này.

Giao diện

Tự ẩn nền: hết thời gian chờ thì ẩn, di chuyển chuột hoặc nhấn phím là hiện lại. Nút "Ẩn giao diện": ẩn khóa cứng, chỉ nhấn Enter mới hiện lại.
